## 一、基础信息

| 项目 | 说明 |
|---|---|
| 项目名称 | 咖啡港湾 COFFEE HARBOR（游戏 / 动漫爱好者社区） |
| 后端技术栈 | Spring Boot 3.2.5 + MyBatis-Plus 3.5.9 + Spring Security + JWT + MySQL 8 |
| 服务地址 | http://localhost:8080 |
| 接口统一前缀 | `/api` |
| 前端地址 | http://localhost:3000（Vite 开发服务器，代理 `/api`、`/picture` 到 8080） |
| 数据交换格式 | JSON（UTF-8） |
| 图片访问路径 | http://localhost:8080/picture/{文件名} |

### 认证方式（JWT）

1. 调用登录 / 注册接口，成功后返回 `token`
2. 后续需要认证的请求，在**请求头**中携带：

```
Authorization: Bearer <token>
```

3. token 有效期 **24 小时**（86400000 毫秒）
4. 未登录 / token 过期访问受保护接口返回 **401**；已登录但权限不足返回 **403**；登录失败过多返回 **429**
5. 前端收到 401 后会清除本地会话并跳转登录页

## 二、统一响应格式

### 2.1 通用响应体 ApiResponse

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 状态码：200 成功 / 400 业务错误 / 403 权限不足 / 404 资源不存在 / 500 服务器内部错误 |
| message | string | 提示信息 |
| data | T | 业务数据（可为 null） |

```json
{ "code": 200, "message": "success", "data": { } }
```

### 2.2 分页响应体 PageResult

| 字段 | 类型 | 说明 |
|---|---|---|
| list | array | 当前页数据列表 |
| total | long | 总记录数 |
| page | int | 当前页码（从 1 开始） |
| size | int | 每页条数 |

```json
{ "list": [], "total": 21, "page": 1, "size": 20 }
```

## 四、认证模块

### 1. 用户登录

- **请求方法**：POST
- **请求路径**：`/api/auth/login`
- **认证要求**：否
- **请求体（JSON）**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |

```json
{ "username": "admin", "password": "admin123" }
```

- **响应示例**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": {
      "id": 1, "username": "admin", "nickname": "管理员",
      "avatar": null, "email": null, "role": "ADMIN",
      "points": 0, "level": "港湾新人 🌱"
    }
  }
}
```

- **备注**：用户名或密码错误统一返回 `400 用户名或密码错误`（不再区分"用户不存在"，防账号枚举）；
  同一 `IP|用户名` 15 分钟内失败 5 次将被锁定 15 分钟，返回 `429`

## 五、帖子模块

### 4. 发布帖子

- **请求方法**：POST
- **请求路径**：`/api/posts`
- **认证要求**：是
- **请求体（JSON）**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| title | string | 是 | 标题，最长 200 字 |
| content | string | 是 | 正文，支持 HTML 标签 |
| category | string | 是 | 板块：`GAME`（单机游戏）/ `ANIME`（动漫） |
| images | string | 否 | 图片 JSON 数组字符串，如 `["/picture/a.jpg"]` |
| links | string | 否 | 相关链接 |
| videos | array | 否 | 视频链接数组，最多 3 个；仅接受 B站 / YouTube / 腾讯视频 / 优酷 / 抖音 / 西瓜视频 的 http(s) 链接 |
| tags | array | 否 | 标签数组，最多 3 个，如 `["攻略","只狼"]` |

```json
{ "title": "只狼通关心得", "content": "<p>正文内容</p>",
  "category": "GAME", "images": "[\"/picture/sekiro.jpg\"]",
  "videos": ["https://www.bilibili.com/video/BV19ycge2EmC"],
  "tags": ["攻略", "只狼"] }
```

- **响应示例**：`data` 为新建的帖子对象（含 id）
- **备注**：发布成功后自动维护 `tags` 表的话题计数；`videos` 会按平台白名单清洗后**抓取标题/封面/时长**
  （B站封面下载到本地 `/picture/video-<BV号>.jpg`），再以对象数组存库；正文 HTML 仍禁止 iframe。

#### 视频元信息（封面自动抓取）

- **请求方法**：GET
- **请求路径**：`/api/videos/meta?url={视频链接}`
- **认证要求**：否（只读公开数据）
- **说明**：发帖页粘贴链接时调用，用于即时预览。仅访问 B站 / YouTube 的固定接口，不接受任意 URL。
- **响应示例**：

```json
{ "code": 200, "message": "success", "data": {
  "url": "https://www.bilibili.com/video/BV19ycge2EmC",
  "provider": "bilibili",
  "videoId": "BV19ycge2EmC",
  "title": "2025只狼！苇名一心平民打法",
  "cover": "/picture/video-BV19ycge2EmC.jpg",
  "durationSeconds": 406,
  "owner": "幽默守恒定律",
  "embeddable": true
} }
```

- `provider`：`bilibili` / `youtube` / `tencent` / `youku` / `douyin` / `ixigua`
- `embeddable=false` 表示该平台没有公开的通用站内播放能力（抖音/西瓜），前端会降级为跳转卡片
- 结果在服务端缓存 6 小时；失败结果缓存 10 分钟，避免频繁打第三方接口

### 5. 帖子列表

- **请求方法**：GET
- **请求路径**：`/api/posts`
- **认证要求**：否
- **请求参数（Query）**：

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| category | string | 否 | — | 板块筛选：GAME / ANIME |
| tag | string | 否 | — | 话题标签筛选，如 `攻略` |
| sort | string | 否 | — | 排序：`hot` 热度榜 / `essence` 只看精华 / 不传为最新（置顶优先） |
| page | int | 否 | 1 | 页码 |
| size | int | 否 | 20 | 每页条数 |

- **响应示例**：

```json
{
  "code": 200, "message": "success",
  "data": {
    "list": [{
      "id": 13, "title": "只狼：苇名一心无伤打法心得",
      "content": "<img src=\"/picture/sekiro.jpg\" /><p>...</p>",
      "category": "GAME", "images": "[\"/picture/sekiro.jpg\"]",
      "links": null, "userId": 2, "authorName": "testuser",
      "likeCount": 0, "collectCount": 0, "commentCount": 0,
      "isTop": false, "isEssence": false,
      "tags": "[\"攻略\",\"只狼\"]",
      "createdAt": "2026-08-23T09:18:05", "updatedAt": "2026-08-23T09:18:05"
    }],
    "total": 21, "page": 1, "size": 20
  }
}
```

- **备注**：热度计算公式 = 点赞数×3 + 收藏数×2 + 评论数×4

## 六、评论模块

### 11. 发表评论 / 回复

- **请求方法**：POST
- **请求路径**：`/api/comments/{postId}`
- **认证要求**：是
- **路径参数**：`postId` 帖子 ID
- **请求体（JSON）**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| content | string | 是 | 评论内容 |

- **响应示例**：

```json
{ "code": 200, "message": "评论成功",

            "createdAt": "2026-08-23T12:30:00" } }
```

- **备注**：会给帖子作者发送「被回复」通知（自己评论自己的帖子不通知）；帖子评论数 +1

## 十八、业务规则速查

| 规则 | 说明 |
|---|---|
| 帖子板块 | `GAME` 单机游戏 / `ANIME` 动漫 |
| 列表排序 | `sort=hot` 热度榜（点赞×3 + 收藏×2 + 评论×4）；`sort=essence` 只看精华；默认最新（置顶优先） |
| 标签限制 | 每个帖子最多 3 个标签，重复自动去重；发帖/改帖/删帖自动维护标签计数 |
| 签到奖励 | 每日一次，+10 积分 |
| 等级体系 | 0–49 港湾新人 🌱 ／ 50–149 港湾常客 ☕ ／ 150–399 港湾老船长 ⚓ ／ 400+ 传奇水手 🌊 |
| 楼中楼 | 评论带 `parentId` 即为回复，前端按父子关系缩进渲染 |
| 通知触发 | 评论他人帖子通知楼主、点赞他人帖子通知楼主；自己操作自己的帖子不产生通知 |
| 论坛帖子正文 | 支持 HTML，但入库前经 jsoup 白名单过滤（保留 p/b/i/u/a/img/h1-h3/ul/ol/li/blockquote/pre/code 等，去掉 script/iframe/事件属性/`javascript:`） |
| 图片存储 | 物理目录 `APP_UPLOAD_DIR`（默认 `picture/`），访问 URL 前缀 `/picture/`，文件名 UUID + 服务端判定扩展名 |
| 计数一致性 | 计数采用 SQL 原子自增；漂移可用 `POST /api/admin/stats/rebuild` 重算 |
| 管理员初始化 | 首次启动自动创建管理员账号：`admin / admin123`（可用 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 覆盖） |
| 数据库升级 | 启动时自动幂等创建 `tags`、`sign_ins`、`announcements`、`notifications` 表及新增列 |

## 十九、错误码说明

| code | HTTP 状态 | 说明 | 常见场景 |
|---|---|---|---|
| 200 | 200 | 成功 | — |
| 400 | 400 | 业务错误 | 参数校验失败、用户名已存在、无权操作、帖子/评论不存在 |
| 403 | 403 | 权限不足 | 非管理员访问 /api/admin/** |
| 401 | 401 | 未登录 / token 过期 | 访问需要登录的接口 |
| 404 | 404 | 资源不存在 | 访问不存在的图片等静态资源 |
| 429 | 429 | 请求过于频繁 | 登录失败次数超过阈值 |
| 500 | 500 | 服务器内部错误 | 未预期的服务端异常（响应体不包含堆栈） |
